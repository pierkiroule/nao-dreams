# NOA SOUCI

> Et si nos soucis pouvaient se composter ?

NOA SOUCI est un rituel numérique sobre : déposer un souci, le laisser se transformer, cueillir des ressources puis composer un texte dont la personne reste co-autrice.

## Développement

```bash
npm install
npm run dev
```

Les ressources de la fleur sont éditables dans `src/data/resources.json`. L'expérience est locale et fonctionne sans périphérique. L'architecture laisse l'entrée libre pour une future couche de lecture NFC, sans en simuler ni en implémenter le fonctionnement aujourd'hui.
